The honest version of this story isn't that AI writes my code now. It's that the parts of the job that used to eat the most hours — boilerplate, first-draft tests, tracing an unfamiliar codebase — take a fraction of the time they used to.

## Where it genuinely helps

- Scaffolding repetitive CRUD and migration code
- Writing a first pass of tests I then tighten by hand
- Explaining unfamiliar parts of a legacy codebase quickly

## Where it doesn't

Architecture decisions, trade-off calls with real business consequences, and anything touching payment logic still get the same scrutiny they always did — if anything, more, since generated code can look confidently correct while being subtly wrong.

## The actual shift

Less time typing, more time reviewing and deciding. The job increasingly looks like being a very fast, very skeptical editor of your own and the assistant's output.
